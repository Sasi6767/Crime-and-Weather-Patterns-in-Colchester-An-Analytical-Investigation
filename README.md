# Crime and Weather Patterns in Colchester: An Analytical Investigation

## Overview
This project presents an in-depth analytical investigation into the relationship between recorded crime patterns and weather conditions in Colchester, UK. Using real-world crime data alongside daily meteorological records, the study explores how environmental factors such as temperature, rainfall, and seasonal variation influence crime frequency and type.

The analysis combines statistical exploration, time series decomposition, spatial analysis, and interactive visualisation techniques to generate actionable insights for public safety planning and data-driven decision-making.

---

## Objectives
- Analyse temporal trends in crime across multiple categories
- Examine correlations between weather variables and crime incidence
- Identify seasonal and daily crime patterns
- Explore spatial crime distributions within Colchester
- Provide interpretable insights to support policy and resource allocation

---

## Dataset
The project integrates multiple datasets:
- **Crime Records (2024–2025)** – Incident-level crime data for Colchester
- **Weather Data (2023–2024, 2024–2025)** – Daily temperature and rainfall records

All datasets were cleaned, validated, and merged to ensure consistency and analytical reliability.

> Note: Data is used strictly for academic analysis.

---

## Methodology
The analysis follows a structured data science workflow:
- Data loading and quality assessment
- Data preprocessing and feature engineering
- Exploratory data analysis (EDA)
- Crime pattern analysis by category and time
- Weather pattern analysis and correlation assessment
- Crime–weather integration analysis
- Time series decomposition
- Spatial analysis and visual mapping
- Executive dashboard and key insights summarisation

## Key Findings

- Warmer days are associated with increased levels of certain crime types
- Rainfall shows a dampening effect on outdoor crimes
- Seasonal trends explain a substantial proportion of crime variability
- Weather variables account for approximately 15–20% of variation in crime patterns
- Spatial clustering reveals distinct crime hotspots within Colchester
